## Projetos em destaque

| Projeto | Stack | O que faz |
|---|---|---|
| [`shopify-theme-gmdscode`](https://github.com/gustamds/shopify-theme-gmdscode) | Liquid, Shopify | Tema Shopify customizado — seções, blocos e ajustes de tema. Trabalho mais recente do perfil. |

| [`clothing-app`](https://github.com/gustamds/clothing-app) · [demo](https://clothing-app-ten.vercel.app) | TypeScript, Next.js | Loja de roupas com Next.js — página de produto, listagem e carrinho. |
| *agência, sem repositório público* | Shopify Hydrogen, React Router, React Three Fiber | E-commerce headless para uma marca de suplementos — protótipo ainda em aprovação de marketing, por isso sem nome. |
| *agência, sem repositório público* | React 19, TypeScript, Vite, Three.js, Motion | Site institucional para uma empresa de engenharia elétrica, com hero interativo, visualizador 3D de soluções técnicas e animações com Motion. |
| *agência, sem repositório público* | Next.js 15, Turborepo, TypeScript | Sistema de gestão de almoxarifado para um órgão público — controle de estoque e requisições internas, em monorepo com API dedicada. |
